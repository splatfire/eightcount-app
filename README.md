# EightCount

Learn dance choreography in 8-counts – a native app for iPhone (incl. iPhone
Duo), iPad, Apple-silicon Macs and an Apple Watch remote.

- The app and its full guide: [`eightcount/README.md`](eightcount/README.md)
- Publishing on the App Store: [`eightcount/APPSTORE.md`](eightcount/APPSTORE.md)
- Privacy policy: [`eightcount/PRIVACY.md`](eightcount/PRIVACY.md)
- Working with Cursor and Claude: [`AGENTS.md`](AGENTS.md), where we left off:
  [`HANDOFF.md`](HANDOFF.md)

Quick start on a Mac:

```sh
git clone https://github.com/splatfire/eightcount-app.git ~/eightcount-app
cd ~/eightcount-app/eightcount && ./setup-mac.sh --install
```
